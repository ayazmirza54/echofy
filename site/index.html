Why Echofy

Dictation that stays on your PC.

Built for people who type all day and would rather not ship their voice to a server to do it.

Push-to-talk

Hold a hotkey to record, release to type. No wake words, no always-on mic.

100% local

Whisper runs on your machine via faster-whisper. Audio never leaves your PC.

How it works

Three steps, all on your machine.

01 · HOLD

Record while held

A beep, then your mic records at 16 kHz mono for as long as the hotkey is down.

[rec] listening...
02 · RELEASE

Transcribe locally

faster-whisper runs the Whisper model on your CPU (or GPU), trimming silence first.

[rec] transcribing 3.6s...
03 · TYPE

Type into any app

The text is typed into whatever window has focus, or pasted if you prefer.

keyboard.write(text)
Install

Up and running in a minute.

Download Echofy.exe

One file, nothing to install. Get the latest release (Windows 10/11, 64-bit).

Run it

A console window opens and shows your hotkey and model. Keep it open while you dictate; close it (or press Ctrl+C) to quit.

Hold Right Ctrl and talk

Put your cursor in any text field, hold the key, speak, release. The first dictation downloads the Whisper model (a few hundred MB, once); after that it works offline.

“Windows protected your PC”? Echofy isn’t code-signed yet, so SmartScreen warns about new downloads. Click More info → Run anyway. The source is on GitHub, and every release is built from it by GitHub Actions.
# Prefer running from source? (Python 3.9–3.12)
git clone https://github.com/ayazmirza54/echofy
cd echofy
run.bat

FAQ

Questions.

Does my audio leave my computer?

No. Recording and transcription both happen locally. The only download is the Whisper model itself, fetched once on first use and cached under your user profile.

Why does Windows or my antivirus warn me?

The .exe isn’t code-signed yet, and it listens for a global hotkey and types keystrokes, which some antivirus tools flag on unknown apps. It’s built from the public source by GitHub Actions; you can also run it from source.

It doesn’t type into some apps.

Windows blocks input into apps running as Administrator from non-elevated apps. If you dictate into an elevated window, run Echofy as Administrator too.

How accurate and fast is it?

base.en is a good default on most CPUs. Move up to small.en or medium.en for accuracy, or down to tiny.en on slow machines. With an NVIDIA GPU, set device to cuda for a big speedup.

Mac or Linux?

Windows only for now.

Can I use it in a Remote Desktop session?

Yes. Run Echofy on the remote machine and set the RDP client’s “Remote audio recording” to “Record from this computer”. Typing needs no setup.
